# Systems Software Engineer (Codecademy)

This repository is my **personal, self-curated collection of Codecademy courses** focused on low-level and systems programming languages — **C**, **C++**, **Rust**, and **Go**.

> **Note:** Codecademy does not offer an official "Systems Software Engineer" path. I put these courses together under that name to guide my own structured learning toward systems programming.

## Goal

To build a strong low-level foundation — understanding memory, pointers, data structures, ownership, and how software interacts closely with the hardware it runs on — and to apply that knowledge by building real compiled programs.

## Education

I am pursuing a **B.Sc. in Computer Science and Engineering (CSE)** at the **Institute of Science and Technology** alongside these courses.

The degree and this repository are part of my broader journey toward becoming a well-rounded software engineer. While my **CSE degree** focuses on my academic curriculum and theoretical foundation, this repository focuses on practical, hands-on systems programming.
